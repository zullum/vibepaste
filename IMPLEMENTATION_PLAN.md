# VibePaste - Voice-to-Text Auto-Paste Tool

Technical implementation plan for a macOS dictation tool using whisper.cpp.

## Overview

VibePaste captures audio from the default microphone, transcribes it using whisper.cpp, and automatically pastes the transcribed text into the currently focused input field.

## Components

### 1. Keyboard Listener Module
- **Library**: `pynput` for global hotkey detection
- **Hotkeys**:
  - `Left Option + E` → English transcription (no language flag)
  - `Left Option + B` → Bosnian transcription (`-l bs`)
- **Behavior**: Toggle mode - press once to START recording, press again to STOP and transcribe

### 2. Audio Recorder Module
- **Library**: `sounddevice` + `scipy` for WAV recording
- **Format**: 16kHz mono WAV (whisper.cpp optimal)
- **Input**: System default microphone
- **Temp File**: `/tmp/vibepaste_recording.wav`

### 3. Transcription Module
- **Tool**: whisper.cpp CLI
- **Model**: `models/ggml-large-v3-turbo.bin`
- **Command Template**:
  ```bash
  # English
  /Users/sanel.zulic/myprojects/whisper.cpp/whisper -m /Users/sanel.zulic/myprojects/whisper.cpp/models/ggml-large-v3-turbo.bin -f /tmp/vibepaste_recording.wav -otxt

  # Bosnian
  /Users/sanel.zulic/myprojects/whisper.cpp/whisper -m /Users/sanel.zulic/myprojects/whisper.cpp/models/ggml-large-v3-turbo.bin -f /tmp/vibepaste_recording.wav -otxt -l bs
  ```
- **Output**: Parse `.txt` file generated by whisper

### 4. Clipboard & Paste Module
- **Library**: `pyperclip` for clipboard, `pyautogui` for paste simulation
- **Flow**:
  1. Copy transcribed text to clipboard
  2. Simulate `Cmd+V` keystroke
  3. Restore original clipboard content (optional)

## macOS Permissions Required

### 1. Microphone Access
- **Location**: System Settings → Privacy & Security → Microphone
- **Required For**: Audio recording via sounddevice
- **Grant To**: Terminal.app or Python executable

### 2. Accessibility Access
- **Location**: System Settings → Privacy & Security → Accessibility
- **Required For**:
  - Global keyboard hooks (pynput)
  - Keyboard simulation for paste (pyautogui)
- **Grant To**: Terminal.app or Python executable

### 3. Input Monitoring (Optional)
- **Location**: System Settings → Privacy & Security → Input Monitoring
- **Required For**: Alternative keyboard monitoring method
- **Note**: May be needed if pynput doesn't work with Accessibility alone

## Usage Flow

```
1. User focuses on text input (any app)
2. User presses Left Option + E (English) or Left Option + B (Bosnian) ONCE
3. Recording starts (audio feedback in console)
4. User speaks
5. User presses the same hotkey combination AGAIN
6. Recording stops → whisper.cpp transcribes → text auto-pastes
7. User continues typing or repeats
```

## Error Handling

| Error | Handling |
|-------|----------|
| No mic access | Show notification, open Privacy settings |
| No accessibility | Show notification, open Privacy settings |
| whisper.cpp fails | Log error, show notification |
| Empty transcription | Skip paste, optional notification |
| Clipboard error | Fallback to just copying (no auto-paste) |
